## 🚀 Quick Start / How to Run Locally

You can open and preview this portfolio immediately with zero build overhead:

### Option 1: Direct File Open
Double click `index.html` or run in terminal:
```bash
open index.html
```

### Option 2: Local HTTP Server (Python)
```bash
python3 -m http.server 3000
# Open http://localhost:3000 in your browser
```

### Option 3: Node / Serve
```bash
npx serve -l 3000 .
# Open http://localhost:3000 in your browser
```

## ⚡ Interactive Features Built-In

1. **Percentage Preloader (0 → 100%)**: Minimalist digital counter with glowing progress bar and smooth entrance reveal.
2. **Dynamic Ambient Plasma Follower**: Fluid radial glowing aura that reacts to mouse position with smooth inertia.
3. **Canvas Starfield & Constellation Grid**: 60fps canvas particles connecting dynamically.
4. **Interactive Linux CLI (Ahad-CLI v1.0)**:
   - Try commands: `whoami`, `academics`, `scores`, `skills`, `roadmap`, `passions`, `football`, `math`, `neofetch`, `help`, `clear`.
   - Includes real command history (Up/Down arrows) and Tab auto-completion!
   - Mini penalty shootout game (`shoot left`, `shoot center`, `shoot right`)!
   - Interactive prime number sequence puzzle (`math 19`)!
5. **Interactive Labs**:
   - Prime Sieve & Fibonacci sequence generator.
   - Java-style LIFO Stack simulator (`push`, `pop`).
   - LLM temperature & entropy playground slider.
6. **Futuristic Sound Design (Optional)**: Web Audio API synthesizer for tactile UI clicks and hums (muted by default, toggleable in header).
7. **3D Card Tilt**: Cards react in 3D perspective to cursor hover coordinates.
8. **Live IST Clock**: Displays the real-time Kolkata / IST time in the footer.
